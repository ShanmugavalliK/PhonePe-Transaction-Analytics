# 📱 PhonePe Transaction Analytics Dashboard

## 📌 Project Overview
This Power BI dashboard analyzes PhonePe transaction data across multiple services including Insurance, Loans, Money Transfer, and Recharge & Bills. The dashboard provides insights into transaction performance, payment status, failed payment reasons, and monthly trends using interactive visualizations.

---

## 🚀 Key Features
- Interactive multi-page dashboard
- Service-wise transaction analysis
- Payment success vs failed transaction tracking
- Failed payment reason analysis
- Monthly amount trend analysis
- Dynamic date range filtering
- KPI cards for quick insights

---

## 🛠️ Tools & Technologies Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Excel / CSV Dataset
